What is Arkanoid?

  • Classic Arcade Game: Originally released by Taito in 1986.
  • Core Objective: Clear all bricks on the screen using a bouncing ball.
  • Player Control: Control the paddle (Vaus) horizontally at the bottom to prevent the ball from falling.
  • Modern Recreation: Built completely from scratch using Python and the Pygame library.
Slide 3 / 7 Project Overview

Game Architecture & Entities

  • Paddle (Player): Listens to keyboard events and moves smoothly along the X-axis.
  • Ball: Tracks velocity vectors (`vx`, `vy`) and updates position every frame.
  • Bricks: Organized in a grid array. Dynamic removal upon collision detection.
  • Game Loop: Continuously handles input, updates physics states, and redraws the screen at 60 FPS.
Slide 4 / 7 Code Structure

Physics & Collision Logic

  • Collision Detection: Checking bounding box intersections between the ball and entities.
  • Wall Bounce: Inverting velocity vectors (`speed_x = -speed_x`) upon hitting boundaries.
  • Paddle Bounce Dynamics: The rebound angle changes depending on where the ball hits the paddle, giving the player tactical control.
